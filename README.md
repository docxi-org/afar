# afar

Двухпанельный файловый менеджер в духе Far Manager со встроенным ИИ-агентом (Claude Code) в нижней панели. Замысел и архитектура — в [docs/](docs/README.md).

**Статус: прототип M0.**

## Запуск

Нужны Rust (stable) и установленный `claude` (Claude Code CLI) в `PATH`. Лучше всего запускать в Windows Terminal.

```
cargo run --release
```

### Режим разработки

```
cargo run --release -- --dev
```

afar сам пересобирается при изменении исходников (`src/`, `vendor/`, `examples/`, `Cargo.toml`, `Cargo.lock`) и перезапускается, сохраняя пути и курсоры панелей, активную панель, размеры окон, режим наблюдения и разговор с агентом. Перезапуск ждёт, пока закрыты диалоги, нет файловых операций и команд, и агент 3 секунды ничего не выводил; `Ctrl+Shift+R` или `afar:restart` — перезапустить сразу. Ошибки сборки — на экране пользователя (`Ctrl+O`) и в списке команд для агента.

## Что умеет прототип

- две файловые панели: навигация, вход в каталоги, выделение (`Ins`, `Shift+↑/↓`), `Ctrl+PgUp` — вверх, `Ctrl+\` — в корень, `Ctrl+R` — перечитать, `Tab` — другая панель;
- командная строка: команды выполняются через `cmd /c`, `cd`/`X:` — встроенные, `Ctrl+Enter` — вставить имя файла, `Ctrl+O` — экран пользователя (вывод команд);
- панель агента с настоящим `claude`: `Ctrl+Space` — переключить ввод между панелями и агентом, `Ctrl+↑/↓` — высота панели агента, `Ctrl+←/→` — граница между панелями (обе границы можно таскать мышью);
- журнал действий (`%LOCALAPPDATA%\afar\sessions\<время>\journal.jsonl`) и вывод каждой команды (`output\cmd-N.log`);
- MCP-сервер для агента: `afar_state`, `afar_journal`, `afar_commands`, `afar_command_output`, `afar_terminal_screen`, `afar_navigate`, `afar_select`;
- режимы наблюдения: по запросу (по умолчанию) и live — команда `afar:live` в командной строке; в режиме live хук Claude Code добавляет к каждому запросу новые события журнала и хвост вывода упавших команд;
- мышь: щелчок — курсор, двойной щелчок — открыть, правая кнопка — выделить, колесо — прокрутка; щелчок по панели агента — фокус; щелчок по строке F-клавиш — нажатие; выделение текста в терминале — с `Shift`;
- `F7` — создать папку (вложенные, несколько через `;`), `F8` / `Del` — удалить в Корзину, `Shift+Del` — безвозвратно, `Shift+F8` — только текущий файл; удаление идёт в фоне с прогрессом и вопросами при ошибках;
- `F5` — копировать, `F6` — перенести/переименовать (`Shift+F5`/`Shift+F6` — текущий файл, на месте); вопросы при существующих файлах, «для всех», «заменять, если новее»;
- агент может создавать папки (`afar_mkdir`), а копировать, переносить и удалять — через ваше подтверждение в диалоге (`afar_copy`, `afar_move`, `afar_delete`);
- `F10` — выход.

## Известные ограничения прототипа

- Нет просмотрщика, редактора, поиска, истории, режимов вида и сортировки — см. [TODO.md](TODO.md).
- Вставка многострочного текста в панель агента: Windows Terminal передаёт её как нажатия клавиш, и перевод строки может отправить запрос раньше времени.
