# Исследование: меню (VMenu), смена диска, быстрый поиск, пометка по маске

Спецификация по исходникам Far Manager 3 (`FarManager/far/`, ссылки `файл:строка` — от этого каталога). Цель — посимвольно повторить отрисовку. Координаты: `ScrX`/`ScrY` — индекс последнего столбца/строки экрана (ширина = `ScrX+1`), деление целочисленное с усечением к нулю. Строки интерфейса — идентификаторы `lng::M…` (тексты в `farlang.templ.m4`; в скобках — англ./рус.).

## 1. VMenu — обычное меню

### 1.1 Устройство

Все меню, о которых идёт речь (сортировка, смена диска), — `VMenu2`: **диалог с единственным элементом `DI_LISTBOX`**, а сам список — `VMenu` в режиме listbox (`vmenu2.cpp:329-368`, `dialog.cpp:744-787`). Следствия:

- Список получает флаги `VMENU_LISTBOX | VMENU_ALWAYSSCROLLBAR` (`dialog.cpp:748`), `DIF_LISTNOAMPERSAND` → `&` — маркер горячей клавиши (`vmenu2.cpp:331`, `dialog.cpp:759`), `VMENU_MOUSEREACTION` → `DIF_LISTTRACKMOUSE` (курсор следует за мышью, `vmenu2.cpp:365,397`).
- Рамка списка: `SHORT_DOUBLE_BOX` (у списка фокус, `vmenu.cpp:186-203`) — символы двойной рамки `╔═╗║╚═╝` (`interf.cpp:1526-1539`).
- Тип рамки диалога `VMenu2::m_BoxType` по умолчанию `full` (`vmenu2.hpp`), `SetBoxType(SHORT_*)` → `thin`.

### 1.2 Ширина, высота, положение

**Естественная ширина списка** (вместе с его рамкой), `GetNaturalMenuWidth` (`vmenu.cpp:3576-3583`, `205-238`):

```
Wn = max(MaxItemLen + 5, max(len(Title), len(BottomTitle)) + 6)
```

- `MaxItemLen` — максимум видимой длины текста пунктов (`HiStrlen`: без одиночных `&`, `&&` = один символ) по **всем** добавленным пунктам, включая разделители с текстом; только растёт (`vmenu.cpp:955-956, 3151-3154`).
- 5 служебных колонок: рамка слева, колонка отметки, колонка `«`, колонка `»`, рамка/полоса прокрутки справа. Колонка `►` (+1) — только если есть пункт-подменю.
- 6 для заголовка: `║═ ` слева и ` ═║` справа (`vmenu.cpp:233-238`).
- Ограничений min/max, кроме ширины экрана, нет.

**Размер окна** (`VMenu2::Resize`, `vmenu2.cpp:210-294`), `n` — число видимых пунктов (разделители считаются, скрытые/отфильтрованные — нет):

| | `full` (по умолчанию) | `thin` |
|---|---|---|
| ширина окна `W` | `min(ScrX+1, Wn+4)` | `min(ScrX+1, Wn)` |
| высота окна `H` | `min(n, MaxHeight если задан) + 4` | `min(n, MaxHeight) + 2` |
| список внутри окна | `(2,1)-(W-3, H-2)` | всё окно |

В режиме `full` окно залито пробелами цвета `COL_MENUBOX` (`vmenu2.cpp:83-85`, `dialog.cpp:1525-1530`): **2 пустые колонки слева и справа от рамки, по 1 пустой строке сверху и снизу**.

**`SetPosition({x, y, 0, 0})`** (`vmenu2.cpp:543-553, 219-293`):
- `x` — столбец **рамки списка**. В `full` окно начинается на 2 левее: `X = x-2` (если `x > 1`); в `thin` — `X = x`.
- `x = -1` — центр по горизонтали: `left = (ScrX+1 - W)/2`; `y = -1` — центр по вертикали: `top = (ScrY+1 - H)/2` (`dialog.cpp:450-469`). В `full` при `y > 0` окно поднимается на 1 (`Y = y-1`).
- Правый край: если `X > 0` и `X+W > ScrX`, то `X = ScrX - W` (последний столбец экрана остаётся свободным, `vmenu2.cpp:263-265`).
- Высота сверх экрана: `mh = (y<0 ? ScrY : ScrY-y) + 2` (в `full`; `+1` в `thin`); если `H > mh`, то `H = mh` (вариант «показать над точкой» — только при заданном `y >= ScrY/2`). Для центрированного меню это даёт `H = ScrY+2`, `top = 0`: рамка списка на строках `1…ScrY`, нижняя пустая строка окна уходит за экран; пунктов видно `ScrY-2`.
- `SetMaxHeight` у самого `VMenu` дополнительно ограничен `ScrY-6` (`vmenu.cpp:3156-3162`), но на размер окна `VMenu2` не влияет.

**Тень** — у окна диалога (`dialog.cpp:1522`, `interf.cpp:1315-1319`): прямоугольники `(right+1…right+2, top+1…bottom)` и `(left+2…right+2, bottom+1)`. Символы не меняются, меняются цвета (`scrbuf.cpp:222-235`): яркий цвет → тот же без яркости, `LIGHTGRAY` → `DARKGRAY`, прочие тёмные → `BLACK` (и фон, и текст); в режиме VT/TrueColor — наложение чёрного с альфой 0x80 (`scrbuf.cpp:303-311`).

### 1.3 Раскладка строки пункта

`menu_layout` (`vmenu.cpp:152-179`). Столбцы относительно левой рамки списка (`Wn` — ширина списка):

| столбец | содержимое |
|---|---|
| 0 | рамка `║` (`COL_MENUBOX`) |
| 1 | отметка: `' '`, `√` (`LIF_CHECKED` без символа) или свой символ (младшие 16 бит флагов, напр. `▲`/`▼`) — цвет текста пункта (`vmenu.cpp:633-642`) |
| 2 | `«` если пункт сдвинут влево (Alt+←), иначе `' '` (`vmenu.cpp:653-660`) |
| 3 … Wn-3 | область текста (ширина `Wn-5`) |
| Wn-2 | `»` если текст не уместился справа, иначе `' '` (`vmenu.cpp:662-669`) |
| Wn-1 | рамка `║`, а в строках, где нужна полоса прокрутки, — полоса |

То есть обычный пункт: `║` + отметка + пробел + текст + пробелы до `Wn-3` + пробел + `║`; от рамки до первой буквы — 2 ячейки, после самого длинного пункта — 1 ячейка.

**Текст** (`DrawItemText`, `vmenu.cpp:2931-2994`): `&` удаляются (`&&` → `&`), `\t` заменяется пробелом; буква горячей клавиши — цветом Highlight; остаток области — пробелами цвета пункта; обрезка по правому краю области (тогда `»` цветом `COL_MENUARROWS`/`…SELECTED`/`…DISABLED`).

**Состояния** (`item_color_indices`, `vmenu.cpp:108-136`) — цвет столбцов 1…Wn-2 целиком:

| состояние | обычный текст | горячая буква |
|---|---|---|
| обычный | `COL_MENUTEXT` | `COL_MENUHIGHLIGHT` |
| под курсором (`LIF_SELECTED`) | `COL_MENUSELECTEDTEXT` | `COL_MENUSELECTEDHIGHLIGHT` |
| `LIF_DISABLE` (фокуса не получает, курсор перескакивает) | `COL_MENUDISABLEDTEXT` | то же |
| `LIF_GRAYED` (фокус есть, выбрать нельзя) | `COL_MENUGRAYTEXT` / под курсором `COL_MENUSELECTEDGRAYTEXT` | то же |

**Разделитель** (`LIF_SEPARATOR`, `vmenu.cpp:2804-2868`): строка во всю ширину списка, цвет `COL_MENUBOX`: `╟` + `─`… + `╢` (у одинарной рамки `├─┤`, `interf.cpp:1664-1665`).
- Текст разделителя: `NW = min(len, Wn-2)`, `NP = (Wn - NW)/2`; ячейка `NP-1` = пробел, `NP…NP+NW-1` — текст (длина «сырая», `&` не обрабатывается), ячейка `NP+NW` = пробел.
- Стыковка с `│` в соседних пунктах (`ConnectSeparator`, `vmenu.cpp:2819-2854`): для каждой позиции текста `I` (с поправкой на `&`): если у пункта выше там `│` и у пункта ниже `│` → в ячейке `3+I` `┼`; только выше → `┴`; только ниже → `┬`. Используется в меню дисков (столбцы `│`).

Строки ниже последнего пункта (если высота задана больше) — пробелы цвета `COL_MENUTEXT` (`vmenu.cpp:2674-2680`).

### 1.4 Клавиши-ускорители справа («Ctrl+F3»)

Это не отдельная колонка: `DecorateItemsWithHotkeys` дописывает имя клавиши в текст до создания меню (`vmenu.cpp:3551-3574`):

```
M = max(HiStrlen(Name)) по всем пунктам (вкл. разделители и пункты без клавиши)
для пункта не-разделителя с AccelKey: Name += ' ' * (M + 1 - HiStrlen(Name)) + KeyToLocalizedText(AccelKey)
```

Имена клавиш выровнены **по левому краю** в колонке, начинающейся через 1 пробел после самого длинного имени (не по правому краю). Формат имени: модификаторы `Ctrl`, `RCtrl`, `Alt`, `RAlt`, `Shift` в этом порядке через `+`, затем клавиша (`keyboard.cpp:274-283, 1453-1532`; `lng::MKeyCtrl`, `MKeyF3`… пусты в обоих языках → английские имена). `KeysToLocalizedText(a, b, …)` — те же имена через пробел (`keyboard.cpp:1534-1537`); символьные клавиши (`'+'`) — сам символ.

`AccelKey` также работает как клавиша выбора: нажатие её в меню ставит курсор на пункт и закрывает меню с ним (`vmenu.cpp:3117-3149`, тип 0).

### 1.5 Заголовки

`DrawTitles` (`vmenu.cpp:2704-2758`), для верхней (строка рамки сверху) и нижней (строка рамки снизу) одинаково: `T = min(len, Wn-4)`, относительный столбец `x = (Wn - 2 - T)/2`; ячейка `x` — пробел, `x+1…x+T` — текст (обрезка справа), `x+T+1` — пробел. Цвет `COL_MENUTITLE`. Пример `Wn = 37`, «Sort by» (7): `═` в столбцах 1–13, пробел 14, текст 15–21, пробел 22, `═` 23–35.

При включённом фильтре верхний заголовок — `«Title [фильтр]»` (при блокировке `<фильтр>`), заголовок обрезается справа, фильтр — слева.

### 1.6 Горячие клавиши пунктов

- Маркер `&` перед буквой (`&&` — литерал). Совпадение (`IsKeyHighlighted`, `dialog.cpp:129-164`): обычная символьная клавиша **или** `Alt+символ`, без учёта регистра. Сначала точное сравнение, затем второй проход с трансляцией раскладки (`KeyToKeyLayoutCompare`: та же физическая клавиша в другой установленной раскладке — русская `с` найдёт `&C`) (`vmenu.cpp:2021-2037`).
- Перебираются пункты по порядку, только способные получить фокус; первый совпавший: курсор на него и меню **сразу закрывается с этим пунктом** (`DN_LISTHOTKEY` → `DM_CLOSE`, `vmenu2.cpp:120-123`, `dialog.cpp:4637-4645`). Закрытие на `LIF_GRAYED`/`LIF_DISABLE` отклоняется (`vmenu2.cpp:113-115`).
- Авто-назначение (`VMENU_AUTOHIGHLIGHT`; в меню сортировки и дисков **выключено**), `AssignHighlights` (`vmenu.cpp:3035-3115`): проход 1 — явные `&`-клавиши, повторная буква (с учётом регистра и другой раскладки) у второго пункта сбрасывается; проход 2 — пунктам без клавиши первая видимая буква/цифра, ещё не занятая. `VMENU_REVERSEHIGHLIGHT` — обход снизу вверх.

### 1.7 Прокрутка и полоса

- Видимых строк `R = высота списка - 2`. Положение верхнего пункта (`AdjustTopPos`, `vmenu.cpp:2760-2802`) по сути: `top = min(top, n - R)`; если курсор ниже окна — `top = sel - R + 1`; если выше — `top = sel`; не меньше 0. Пустых строк внизу при прокрутке не бывает.
- Полоса прокрутки (`vmenu.cpp:254-265, 2697-2701`): при `n > R` (и `R >= 2`), рисуется **вместо правой рамки** в строках `top+1…bottom-1` списка, цвет `COL_MENUSCROLLBAR`; углы рамки остаются. Символы `▲`, `░` (фон), `█` (бегунок), `▼` (`interf.cpp:1640-1650`). Бегунок (`interf.cpp:1579-1638`): `F = R-2`, `rnd(a,b) = round(floor(a/b*F*10)/10)`; `begin = max(top?1:0, rnd(top,n))`, если `top>0` и `begin=0` → 1, если `begin=F` → `F-1`; `size = max(1, rnd(R,n))`; `end = (top+R ≥ n) ? F : begin+size`; если `end=F` и `top+R<n` → `end--`, и если `begin>1` → `begin--`; заполнены ячейки поля `begin…end-1`.
- Горизонтальный сдвиг текста: `Alt+←/→` (все пункты на 1), `Ctrl+Alt+←/→` (на 20), `Alt+Shift+←/→` (текущий), `Alt+Home/End` (в начало/конец) (`vmenu.cpp:1834-1889`).

### 1.9 Клавиши (`vmenu.cpp:1653-2068`, `dialog.cpp:2470-2527`)

- `Up`/`Down` (и `Left`/`Right` — то же самое, `1920-1934`): на соседний доступный пункт, разделители и `LIF_DISABLE` пропускаются. С `VMENU_WRAPMODE` (оба меню ниже) с первого на последний и обратно — **только для неповторного нажатия**; при автоповторе останавливается на краю (`stop_on_edge = IsRepeatedKey()`, `vmenu.cpp:773-819`).
- `Home`/`Ctrl+Home`/`Ctrl+PgUp` — первый доступный; `End`/`Ctrl+End`/`Ctrl+PgDn` — последний (без зацикливания).
- `PgUp`/`PgDn` — на `R` пунктов (высота списка − 2), с ограничением первым/последним; если попали на недоступный — ближайший доступный в направлении движения.
- `Enter`/`NumEnter` — закрыть с текущим пунктом (отклоняется на grayed/disabled). `Esc`, `F10` — закрыть с −1 (`dialog.cpp:2522-2527`). `F1` — справка меню.
- `Gray+ - * /` превращаются в символы `+ - * /` до проверки горячих клавиш (`vmenu.cpp:1716-1729`), но обработчик меню (`Run`) видит их раньше.
- Фильтр печатью **по умолчанию выключен**. Вкл/выкл: `Ctrl+Alt+F` или одиночный правый `Alt` (`1936-1945`); блокировка `Ctrl+Alt+L`; при включённом фильтре символы и `BS` идут в фильтр: скрываются пункты, чей текст (без `&`, обрезанный) не содержит строку фильтра без учёта регистра; разделитель перед пустой группой скрывается (`1131-1233`).
- Самостоятельный `VMenu` без видимых пунктов: любая клавиша, кроме `F1`, `Shift+F1`, `F10`, `Esc`, `Alt+F9` (и клавиш фильтра), закрывает меню с −1 (`1704-1714`).

### 1.10 Мышь (`vmenu2.cpp:653-671`, `dialog.cpp:3093-3160`, `vmenu.cpp:2086-2321`)

- Нажатие вне окна (с полями): левая — отмена, средняя — выбор текущего, правая — отмена (настройки `VMenu.LBtnClick/MBtnClick/RBtnClick`, умолчания `config.cpp:2255-2257`). Срабатывает на нажатие.
- Движение мыши над пунктами без кнопок — курсор следует за мышью (track mouse).
- Левая кнопка над пунктом: на нажатие курсор ставится на пункт; **выбор — на отпускание** в той же ячейке, где было нажатие (иначе только перемещение курсора); двойной щелчок — выбор.
- Нажатие на столбцы `«` (рамка+2) и `»` (правая рамка−1) — горизонтальный сдвиг, а не выбор пункта (`vmenu.cpp:2144-2156`).
- Нажатие и удержание на верхней/нижней строке рамки — прокрутка курсора вверх/вниз, пока держат. Полоса: `▲`/`▼` с автоповтором, тяга бегунка — курсор на `(n-1)*(y-top)/(высота-3)` (`2158-2234`).
- Колесо: курсор и верхний пункт сдвигаются на 1 одновременно (`KEY_MSWHEEL_UP/DOWN`, `1905-1918`), без зацикливания.

## 3. Меню смены диска (`Alt+F1`/`Alt+F2`), `diskmenu.cpp`

## 4. Быстрый поиск (`Alt+буква`), `fastfind.cpp`

**Запуск** (`filelist.cpp:2618-2623`): `Alt+символ`, `RAlt+символ`, `Alt+Shift+символ` с кодом символа < 65536, кроме `BS`, `Tab`, `Enter`, `Esc` и расширенных клавиш (F-клавиши, стрелки). Первая клавиша обрабатывается как ввод: символ берётся из события с учётом текущей раскладки (`fastfind.cpp:64-74`) и переводится в нижний регистр (`133-141`).

**Окно** (`fastfind.cpp:278-285, 313-326`), 22×3, без тени:
- `FindX = min(panel.left + 9, ScrX - 22)`, `FindY = min(panel.bottom, ScrY - 2)` — верхняя рамка окна ложится на нижнюю рамку панели (строки окна обычно: рамка панели, командная строка, строка клавиш).
- Двойная рамка `(FindX, FindY)-(FindX+21, FindY+2)` цветом `COL_DIALOGBOX` (BLACK on LIGHTGRAY); заголовок с `FindX+7`: пробел + `MSearchFileTitle` («Search» / «Поиск») + пробел, `COL_DIALOGBOXTITLE` (BLACK on LIGHTGRAY), **не по центру**.
- Строка `FindY+1`: `║`, пробел `COL_DIALOGTEXT` (BLACK on LIGHTGRAY) в `FindX+1`, поле ввода `FindX+2…FindX+19` (18 ячеек, `COL_DIALOGEDIT` BLACK on CYAN, выделение `COL_DIALOGEDITSELECTED` WHITE on BLACK), пробел в `FindX+20`, `║`. Курсор — в поле.

**Сопоставление** (`FileList::FindPartName`, `filelist.cpp:3709-3758`):
- Маска = введённое + `*`; `[` и `]` экранируются (`exclude_sets`), `*` и `?` работают как подстановки; без учёта регистра; только имя (длинное), «современный» режим `CmpName` (`*.` не равно «без расширения»). Итого — **префикс с подстановками**.
- Завершающий `\` или `/` — искать только каталоги. `..` не находится.
- Поиск: от текущего файла (включительно) вниз до конца, затем с начала до текущего. При находке: курсор на файл, `top = cur - (panel.height - 1)/2` (полная высота панели с рамками), потом обычное ограничение `0 ≤ top ≤ count - stripes*height` (`filelist.cpp:621-642`).

**Клавиши** (`fastfind.cpp:90-230`):
- Печатный символ (32…65535, вкл. `Alt+символ` и `Alt+Shift+символ` → строчная буква, `Gray*` → `*`): добавляется; `**` схлопывается, ведущая `"` удаляется. **Если совпадения нет — строка откатывается к прежней (символ отвергается молча).**
- `BS`, `Ctrl+BS`, `Ctrl+Y`, `Ctrl+Ins` — обычное редактирование/копирование в поле (после `BS` поиск повторяется по оставшейся строке); `Ctrl+V`/`Shift+Ins` — вставка: к строке добавляется буфер, затем укорачивается с конца до первой находки (`95-105`, `299-311`).
- `Ctrl+Enter` — следующее совпадение (от `cur+1` вниз с переходом в начало), `Ctrl+Shift+Enter` — предыдущее (от `cur-1` вверх с переходом в конец). `F1` — справка.
- `Esc`, `F10` — закрыть, клавиша **не** передаётся дальше.
- Любая другая клавиша (код < 32 или ≥ 65536: `Enter`, `Tab`, стрелки, `Del`, F-клавиши, `Ctrl+буква`, `Gray+`/`Gray-` …), кроме одиночных модификаторов, — закрыть и **передать её панелям** (`Enter` откроет найденное, стрелка сдвинет курсор) (`panel.cpp:112-133`).
- Мышь: нажатие левой или правой кнопки — закрыть без передачи (`232-238`). Колесо приходит не как событие мыши, а как клавиша `KEY_MSWHEEL_*` (`manager.cpp:637-641`, `keyboard.cpp:2020-2026`) → по общему правилу закрывает поиск и передаётся панели.

## 5. Пометка по маске (`filelist.cpp:1305-1378, 4114-4340`)

**Диалог** (`Gray+` / `Gray-`): размер 55×7, по центру экрана (`(ScrX+1-55)/2, (ScrY+1-7)/2`); элементы (координаты от окна):
- `DI_DOUBLEBOX (3,1)-(51,5)`, заголовок `MSelectTitle` («Select» / «Пометить») или `MUnselectTitle` («Deselect» / «Снять»);
- `DI_EDIT (5,2)-(49,2)` с историей `Masks`, фокус; стрелка истории `↓` в столбце 50 (`dialog.cpp:1970-1974`);
- разделитель в строке 3 на всю рамку (`╟─…─╢`);
- строка 4, кнопки группой по центру: `MOk` («OK», по умолчанию), `MSelectFilter` («&Filter» / «&Фильтр»), `MCancel` («Cancel» / «Отмена»).
- Начальная маска — последняя введённая в этом сеансе (общая для пометки и снятия), исходно `*.*` (`4143`). Ошибка в маске — предупреждение `MWarning`/`MIncorrectMask` («File-mask string contains errors») и снова диалог. «Фильтр» — меню фильтров, пометка по выбранному фильтру.

**Клавиши** (все сначала сохраняют пометку для `Ctrl+M`):

| клавиша | действие |
|---|---|
| `Gray+` / `Gray-` | диалог; пометить / снять по маске |
| `Shift+Gray+` / `Shift+Gray-` | пометить всё / снять всё (`1305-1333`) |
| `Ctrl+Gray+` / `Ctrl+Gray-` | по расширению текущего: маска `"*.ext"` (без расширения — `*.`) |
| `Alt+Gray+` / `Alt+Gray-` | по имени текущего: маска `"name.*"` (совпадает и с `name` без расширения) |
| `Gray*` | инвертировать |
| `Ctrl+Gray*` | инвертировать, включая каталоги |
| `Alt+Gray*` | инвертировать только файлы |
| `Ctrl+M` | восстановить предыдущую пометку; это обмен «текущая ↔ сохранённая», повтор возвращает обратно (`4676-4691`) |

В `Ctrl/Alt+Gray±` скобки `[` `]` в имени экранируются как `[[]`, `[]]`. Клавиши работают при любой командной строке (панель получает клавишу раньше неё, `filepanels.cpp:790-791`).

**Каталоги** (`4318-4330`): опция `SelectFolders` («Select &folders», `MConfigSelectFolders`) **по умолчанию выключена** (`config.cpp:2083`). Тогда `Gray+`, `Shift+Gray+`, `Ctrl/Alt+Gray+` и `Gray*` каталоги **не помечают** (но снятие пометки с каталогов работает: `Gray-`, `Gray*` с помеченного каталога снимает). `Ctrl+Gray*` и пометка через фильтр каталоги помечают всегда; `Alt+Gray*` не помечает их даже при `SelectFolders`. `..` не помечается никогда (`2635-2638`). После пометки при «помеченные вперёд» список пересортировывается.

**Синтаксис масок** (`filemasks.cpp:60-300`, `processname.cpp:147-280`):
- Разделители `,` и `;` (пробелы вокруг игнорируются); маску с разделителями — в кавычки `"…"`; внутри `[…]` разделители не действуют.
- `*` — любая последовательность, `?` — один символ, `[abc]`, `[a-z]` — набор; регистр не важен.
- `*.*` = `*` (и файлы без расширения); режим совместимости: маска, кончающаяся на `.*`, совпадает с именем без расширения (`name.*` ~ `name`), а `*.` — с именами без точки. `**` схлопывается в `*`.
- `|` — дальше исключения: `*.cpp,*.h|test*` (второй `|` обрывает разбор); только исключения → включение `*`.
- `/regex/опции` — регулярное выражение (поиск, не полное совпадение), можно вперемешку с обычными масками.
- `<группа>` — подстановка из настроек `Masks` (по умолчанию `<arc>`, `<temp>` = `*.bak,*.tmp`, `<exec>` = `*.exe,*.cmd,*.bat,*.com,%PATHEXT%`); `%PATHEXT%` раскрывается в `*.ext,…`.

## 6. Панели: `Ctrl+U`, `Ctrl+P`, `Ctrl+F1`, `Ctrl+F2` (`filepanels.cpp`)

- **`Ctrl+F1`** (`420-439`): левая видима → скрыть; если правая видима — фокус на правую. Левая скрыта → если правая тоже скрыта, фокус на левую; показать левую. Фокус при показе не переходит, если правая видима. **`Ctrl+F2`** — зеркально (`441-459`).
- **`Ctrl+P`** (`582-597`): только если активная панель видима — скрыть/показать **пассивную**; фокус не меняется. Если обе скрыты — ничего (только перерисовка).
- **`Ctrl+U`** (`606-614`, `SwapPanels` `337-350`): если обе панели скрыты — клавиша уходит в командную строку. Иначе объекты панелей меняются местами целиком (каталог, режим вида, сортировка, курсор, пометка, видимость, фильтры панелей); активной остаётся та же панель — фокус «переезжает» на другую сторону. Ширины/высоты (`WidthDecrement`, `Left/RightHeightDecrement`) привязаны к сторонам и остаются на месте. Скрытая панель после обмена тоже окажется на другой стороне.
