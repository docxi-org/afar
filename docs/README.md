# afar — файловый менеджер в духе Far со встроенным ИИ-агентом

> Рабочее название: **afar** (agent + far). Может быть изменено.

Двухпанельный консольный файловый менеджер, визуально и по клавиатуре близкий к Far Manager, в котором ИИ-агент (Claude Code) — не внешний инструмент, а часть приложения: живёт в собственной панели под файловыми панелями, видит действия пользователя и может управлять менеджером так же, как пользователь.

## Коротко

- **Язык и стек:** Rust, `ratatui` + `crossterm` (TUI), `tokio` (асинхронность), `portable-pty` (ConPTY / Unix pty), `vt100` + `tui-term` (эмуляция терминала в панели), `rmcp` (MCP-сервер), `notify` (слежение за ФС).
- **Платформы:** в первую очередь Windows 10 1809+ / 11 (ConPTY), затем Linux и macOS.
- **Главная архитектурная идея:** любое действие — это *команда*. Клавиатура, макросы и MCP-инструменты агента вызывают одни и те же команды; каждая исполненная команда и каждое изменение состояния попадают в *журнал событий*. Отсюда бесплатно получаются и наблюдение агента за пользователем, и наглядность действий агента для пользователя.
- **Агент:** настоящий `claude` CLI, запущенный во встроенном терминале в нижней панели. Он подключается к MCP-серверу, работающему внутри afar, и получает журнал событий через хуки Claude Code.

2. Лицензия afar (предлагается MIT или BSD-3-Clause — совместимо с переносом логики из Far).

5. Механизм расширений (Lua / WASM / только MCP) — решение откладывается до этапа 5.
