# 09. Интерфейс Far: справочник для точного повторения

Собрано из исходников Far Manager 3 (`../FarManager/far`, BSD-3-Clause). Ссылки вида `copy.cpp:648` — на эти исходники. Строки на русском — дословно из `far/farlang.templ.m4` (там 13 языков; порядок: Rus, Eng, Cze, Ger, Hun, Pol, Spa, Sky, Ita, Ukr, Bel, Lit, Por; для каждого идентификатора первая строка в кавычках — русская). `&` — горячая буква.

## 1. Общие правила отрисовки диалогов (dialog.cpp, interf.cpp)

- Диалог W×H центрируется: `left=(cols−W)/2`, `top=(rows−H)/2`; весь прямоугольник заливается пробелами цвета Dialog.Text.
- Рамка `DI_DOUBLEBOX` по соглашению в (3,1)–(W−4,H−2): 3 пустых столбца слева и справа, 1 пустая строка сверху и снизу. Двойная `╔═╗║╚╝`, одинарная `┌─┐│└┘`.
- Заголовок: обрезка до ширины рамки − 2, вид `" Заголовок "`, по центру верхней границы (`X = X1 + (CW−len)/2`), цвет Dialog.Box.Title (чёрный на светло-сером).
- Тень: строка под диалогом (x от left+2 до right+2) и два столбца справа (x right+1..right+2, y top+1..bottom). Символы остаются, цвета тускнеют: яркий → обычный, светло-серый → тёмно-серый, остальные → чёрный (и текст, и фон).
- Разделитель `DIF_SEPARATOR`: `╟───╢` от x=3 длиной W−6 (перекрывает вертикали рамки); `DIF_SEPARATOR2` — `╠═══╣`; текст разделителя — по центру с пробелами.
- `DI_TEXT`: `X1=−1` — по центру диалога.
- Флажок: `[x] Текст` / `[ ] Текст` (третье состояние `[?]`), курсор на X1+1.
- Переключатель: `(•) Текст` / `( ) Текст` (точка U+2022).
- Кнопка: `[ Текст ]`; кнопка по умолчанию `{ Текст }`; `DIF_NOBRACKETS` — без скобок.
- `DIF_CENTERGROUP`: элементы одной строки — группа; длина = Σ(видимая длина со скобками + 1) − 1 (кнопки через один пробел), `StartX = (W − длина)/2`; флажок/переключатель в группе считается как len+5.
- Поле ввода / список: занимают ровно X1..X2; при истории или списке в X2+1 рисуется `↓` цветом текста диалога.
- Цвета:

| Элемент | Обычный диалог | Предупреждение |
|---|---|---|
| Текст, рамка | чёрный на светло-сером | белый на красном |
| Горячая буква | жёлтый на светло-сером | жёлтый на красном |
| Кнопка | чёрный на светло-сером | белый на красном |
| Кнопка в фокусе | чёрный на бирюзовом (буква жёлтая) | чёрный на светло-сером (буква жёлтая) |
| Поле ввода | чёрный на бирюзовом; нетронутый текст — светло-серый на бирюзовом | так же |
| Недоступно | тёмно-серый | тёмно-серый |

### Message() (message.cpp:163-435)

- MaxLength = max(самая длинная строка, заголовок+2, кнопки = Σ(видимая длина+5) − 1), не больше max(cols−11, кнопки).
- W = MaxLength + 10; рамка (3,1)–(W−4,H−2); текст в столбцах 5..W−6.
- H = строк + 4, плюс 2, если есть кнопки.
- Строки с Y=2: по центру (или с X=5 при `MSG_LEFTALIGN`); строка из `\1` — разделитель, `\2` — двойной. Строки не переносятся (кроме текста системной ошибки); слишком длинная — поле только для чтения с прокруткой.
- Перед кнопками — разделитель (если последняя строка не разделитель); кнопки на Y=H−3 группой по центру; первая — по умолчанию.
- Системная ошибка добавляется после разделителя, с переносом: например «0x00000005 - Отказано в доступе.»

## 4. Удаление (delete.cpp)

| Режим | Заголовок | Вопрос | Кнопка | Вид |
|---|---|---|---|---|
| В Корзину (F8) | «Удаление» | «Вы хотите переместить {0} в Корзину?» | «Переместить» | обычный серый |
| Удаление (Shift+Del) | «Удаление» | «Вы хотите удалить {0}?» | «Удалить» | предупреждение (красный) |
| Уничтожение (Alt+Del) | «Уничтожение» | «Вы хотите уничтожить {0}?» | «Уничтожить» | предупреждение |

- {0}: «файл», «папку», «объекты»; вторая кнопка «Отмена» (без горячих букв).

- Непустая папка: предупреждение «Удаление папки» / «Данная папка будет удалена:» (в Корзину — «Данная папка будет перемещена в корзину:») / путь; кнопки «&Удалить» (или «Переместить»), «&Все», «&Пропустить», «&Отменить».
- «Только для чтения»: «Предупреждение» / `Файл имеет атрибут "Только для чтения"` / имя / «Вы хотите удалить его?»; кнопки «&Удалить», «&Все», «&Пропустить», «П&ропустить все», «&Отменить».

- Выделение: тот же формат с полным числом байт с разделителями, на разделителе над строкой состояния, жёлтый на бирюзовом.
