# 06. План работ

Порядок выбран так, чтобы как можно раньше проверить главную гипотезу — что агент в нижней панели, видящий действия пользователя, действительно удобен, — и только потом вкладываться в объёмные функции.

## M0. Прототип (несколько дней)

**Цель:** проверить раскладку, фокус, встроенный терминал с `claude` и связку «журнал + MCP».

Состав:
- две файловые панели (локальная ФС, один режим вида «полностью»), курсор, вход в каталоги, выход вверх, `Ins`-выделение, `Ctrl+R`;
- тема `far-classic`, рамки, заголовки с путём, строка статуса панели, keybar;
- командная строка: ввод, `Enter` → выполнение через `cmd /c` в сессии оболочки, `cd` — встроенная, `Ctrl+Enter` — вставка имени, `Ctrl+O` — режим терминала;
- панель агента: PTY-сессия с `claude`, ввод и вывод, `resize`, переключение фокуса `Ctrl+Space`, высота `Ctrl+Up/Down`;
- журнал: `DirChanged`, `SelectionChanged`, `CommandStarted/Finished`; в памяти и в JSONL;
- захват вывода команд из эмулятора в `output/<cmd_id>.log` (текст, без полос прогресса и VT); хвост вывода упавших команд — в режиме live;
- MCP-сервер: `afar_state`, `afar_journal`, `afar_navigate`, `afar_select`, `afar_commands`, `afar_command_output`, `afar_terminal_screen`;
- запуск `claude` с `--mcp-config` и хуком `UserPromptSubmit` (режим live / on-demand);
- `F10` — выход.

Критерии готовности:
1. afar запускается в Windows Terminal, панели выглядят как в Far, навигация не медленнее, чем в Far, на каталоге из 10 000 файлов.
2. В панели агента работает интерактивный `claude`: ввод, вывод с цветами, `Esc`, `Ctrl+C`, многострочный ввод, вставка из буфера.
3. Пока агент отвечает, можно переключиться на панели и работать — интерфейс не замирает.
4. На вопрос «в каких каталогах я был и какие команды запускал?» агент отвечает по журналу.
5. Пользователь запускает падающую сборку из командной строки afar и спрашивает «почему упало?» — агент видит вывод без копирования вручную.
6. По просьбе «покажи файл X» агент переводит панель и ставит курсор на файл.

**Решение после M0:** продолжаем ли с терминальной панелью агента, переходим ли на структурированный режим ([04-agent.md](04-agent.md#развитие-структурированный-режим)) или делаем оба.

## M1. Ядро файлового менеджера

- движок операций: копирование, перемещение, переименование, создание каталогов, удаление (корзина и безвозвратно) — с конфликтами, ошибками, прогрессом, фоном ([05-file-operations.md](05-file-operations.md));
- диалоги F5/F6/F7/F8 в стиле Far;
- выделение по маске, инверсия; быстрый поиск `Alt+буква`;
- режимы вида `Ctrl+1…0`, сортировки `Ctrl+F3…F12`;
- выбор диска `Alt+F1/F2`, `Ctrl+U`, `Ctrl+P`, `Ctrl+F1/F2`;
- слежение за ФС, сохранение курсора и выделения при перечитывании;
- конфигурация `config.toml`, раскладка `keymaps/far.toml`;
- журнал: события файловых операций; MCP: `afar_mkdir`, `afar_copy`, `afar_move`, `afar_rename`, `afar_delete`, `afar_tasks`; политика разрешений и диалоги подтверждения для агента.

Критерий: можно неделю пользоваться afar вместо Far для повседневной работы с файлами, не теряя данных.

## M2. Просмотр, поиск, история

- экраны просмотрщиков и редакторов, список экранов `F12`;
- встроенный просмотрщик `F3` (текст, кодировки, hex, поиск, большие файлы), агент в просмотре: `afar_view`, `afar_highlight`, протокол IDE ([11-viewer-editor.md](11-viewer-editor.md));
- базовый встроенный редактор `F4` (буфер с версиями, отмена, слои подсветки) и совместная работа с агентом в нём — внешний редактор её не даёт; внешний редактор — по настройке, `Shift+F4`;
- быстрый просмотр `Ctrl+Q`, информационная панель `Ctrl+L`;
- поиск файлов `Alt+F7` (по маске и содержимому, в фоне, результат — во временной панели);
- истории команд, каталогов, просмотра (SQLite) — `Alt+F8`, `Alt+F12`, `Alt+F11`;
- атрибуты `Ctrl+A`, раскраска файлов по маскам, справка `F1`;
- строка меню `F9` со всеми командами.

## M3. Агент в полную силу

- хук `PostToolUse` → `AgentToolUsed`, подсветка правок агента, атрибуция изменений ФС;
- `afar_notify`, `afar_run_command`;
- хук `SessionStart`, дополнение к системному промпту, режим «пауза», маскировка чувствительных данных в журнале;
- управление сессией: перезапуск, `--continue`, перезапуск в текущем каталоге;
- пользовательское меню `F2` (в том числе пункты «спросить агента о выделенных файлах»).

## M4. Расширенные функции

- редактор целиком: блоки, поиск/замена, кодировки, макросы — поверх базового из M2;
- архивы как ФС (zip, 7z, tar) — `Enter` на архиве;
- дерево каталогов `Ctrl+T`, ссылки `Alt+F6`, сравнение каталогов;
- темы, сохранение раскладки и состояния панелей между запусками.

## M5. Дальше

- SFTP/FTP как ФС;
- структурированный режим чата (если решили после M0);
- несколько сессий агента (вкладки в панели агента);
- механизм расширений (Lua / WASM / только MCP);
- сборки для Linux и macOS, пакеты (winget, scoop, cargo install).

## Риски

| Риск | Вероятность | Чем грозит | Что делаем |
|---|---|---|---|
| Неполная эмуляция терминала в `vt100` (синхронный вывод, отдельные последовательности, которые использует Claude Code) | средняя | артефакты в панели агента | проверить на M0 в первую очередь; запасной вариант — `alacritty_terminal` |
| Ввод на Windows: различение сочетаний (`Ctrl+Space`, `Ctrl+M` и `Enter`, `AltGr`), вставка | средняя | часть клавиш Far не работает | `crossterm` на Windows читает `INPUT_RECORD` — проверить на M0; при проблемах — собственный слой ввода через WinAPI |
| Расхождение ширины символов между afar, ConPTY и внешним терминалом | средняя | сдвиги в выводе агента и в именах файлов с эмодзи/CJK | `unicode-width` и единые таблицы; тесты на снимках |
| Производительность на больших и сетевых каталогах | низкая | подвисания | потоковое чтение каталогов в фоне, виртуализация списка |
| Ошибки в файловых операциях | низкая, но цена высокая | потеря данных | тестовая матрица из [05-file-operations.md](05-file-operations.md), корзина по умолчанию, запись через временный файл |
| Изменения CLI и хуков Claude Code | средняя | ломается запуск или режим live | генерация конфигурации в одном модуле, дымовой тест при старте (`claude --version`), понятное сообщение об ошибке |
| Объём работ («ещё одна функция Far») | высокая | проект не доходит до пригодного состояния | строгие этапы; критерий M1 — замена Far в повседневной работе, всё остальное — после |
