# 16. Расширенный вывод в терминал

Что современный терминал умеет сверх «текст + 16 цветов», какие из этих возможностей доходят через afar до экрана (программы в PTY, сам Claude Code в панели агента) и какие afar может использовать сам. Сводка-справка (2026-10-07): карта возможностей, проверка звена ConPTY и список доработок-кандидатов; доработки внесены в `TODO.md` (M2, «Вывод в терминал»), порядок там.

Отметка «?» в таблицах — поддержка не проверена, перед использованием проверить на живом терминале.

## Как сделано «переливание» в Claude Code

Это обычная анимация: строку статуса (глагол рядом со спиннером) перерисовывают несколько раз в секунду, и у каждого символа свой цвет в 24-битном формате `ESC[38;2;R;G;Bm`. Градиент сдвигается от кадра к кадру, и получается «блеск». Отдельной последовательности «мерцающий текст» нет. Нужны только truecolor и частая перерисовка, желательно в синхронном кадре (`?2026`), чтобы не было мерцания.

## Возможности

| 256 цветов | `38;5;N`, `48;5;N` | да |
| Truecolor (24 бита) | `38;2;R;G;B`, `48;2;R;G;B` | да |
| Жирный, тусклый | `1`, `2` (сброс `22`) | да |
| Курсив | `3` | да |
| Подчёркивание | `4` | да |
| Двойное подчёркивание | `21` или `4:2` | да |
| Волнистое, точками, пунктиром | `4:3`, `4:4`, `4:5` | да? |
| Цвет подчёркивания | `58;2;R;G;B`, `58;5;N` | да? |
| Мигание | `5` | да |
| Инверсия | `7` | да |
| Скрытый текст | `8` | да |
| Зачёркнутый | `9` | да |
| Линия над текстом | `53` | да |

### Размер и форма символов

- **Строки двойной ширины и высоты** (VT100): `ESC#6` — двойная ширина, `ESC#3`/`ESC#4` — верхняя и нижняя половины двойной высоты. Действует на всю строку. Windows Terminal поддерживает.
- **Текст произвольного размера**: протокол kitty `OSC 66`. Только kitty.
- **Ширина символов.** Эмодзи и восточноазиатские символы занимают две клетки. Терминалы расходятся в ширине эмодзи с модификаторами и составных последовательностей (ZWJ, VS16), отсюда «съезжающие» строки. Режим `?2027` (кластеры графем) включает единые правила там, где он есть.

### Графика

| Способ | Что это | Windows Terminal |
|---|---|---|
| Sixel | растр в DCS-последовательности, старый стандарт DEC | да, с 1.22 |
| Протокол графики kitty | растр (PNG или пиксели) с id, размещение, анимация | нет |
| iTerm2 inline images | `OSC 1337;File=…` | нет? |
| Полублоки `▀▄` | 2 «пикселя» по вертикали на клетку, цвет текста и фона | да (любой терминал) |
| Шрифт Брайля `⣿` | 2×4 точки на клетку, один цвет: графики, спарклайны | да |
| Секстанты 🬀 и октанты | 2×3 и 2×4 блока (Unicode 13 и 16, Legacy Computing) | зависит от шрифта |
| Рамки, иконки Nerd Font | псевдографика, значки файлов и папок | рамки — да, значки — со шрифтом Nerd Font |

Готовые решения для ratatui: виджет `Canvas` (Брайль и полублоки), крейт `ratatui-image` (Sixel, kitty, iTerm2, полублоки как запасной вариант).

### Взаимодействие с терминалом и системой (OSC и режимы)

| Возможность | Последовательность | Windows Terminal |
|---|---|---|
| Гиперссылка: текст кликабелен, адрес скрыт | `OSC 8 ;; URL ST текст OSC 8 ;; ST` | да |
| Заголовок окна или вкладки | `OSC 0` / `OSC 2` | да |
| Текущий каталог (новая вкладка открывается в нём) | `OSC 7` / `OSC 9;9` | да |
| Разметка команд: приглашение, команда, вывод, код выхода | `OSC 133;A/B/C/D` | да (переход между командами, выделение вывода) |
| Прогресс на кнопке панели задач | `OSC 9;4;состояние;процент` | да |
| Уведомление | `OSC 9;текст` / `OSC 777;notify;…` | ? |
| Запись в буфер обмена (работает и через SSH) | `OSC 52;c;base64` | да (только запись) |
| Палитра, цвет текста и фона, их запрос | `OSC 4`, `OSC 10`, `OSC 11` | да |
| Цвет курсора | `OSC 12` | да? |
| Форма курсора: блок, черта, подчёркивание, мигание | `CSI N SP q` (DECSCUSR) | да |
| Звонок | `BEL` | да (звук или значок на вкладке) |

### Ввод и режимы экрана

- Мышь: `?1000` / `?1002` / `?1003` (нажатия, перетаскивание, любое движение), кодировка `?1006` (SGR).
- События фокуса окна `?1004`, вставка с пометкой `?2004` (bracketed paste).
- Расширенная клавиатура: протокол kitty (`CSI > флаги u`, различает `Ctrl+I` и `Tab`, сообщает об отпускании клавиш); в Windows — win32-input-mode (`?9001`), им ConPTY и так передаёт клавиши.
- Альтернативный экран `?1049`: полноэкранная программа не портит историю прокрутки.
- Области прокрутки `CSI верх;низ r` (DECSTBM): прокрутка части экрана.
- **Синхронный вывод `?2026`**: терминал показывает кадр целиком после `?2026l`. afar использует его в обе стороны: оборачивает свой кадр (`Tui::draw`) и учитывает кадры программ в PTY (`term::view`).

## Путь вывода в afar

Программа в панели (команда, Claude Code) доходит до экрана через пять звеньев, и каждое может что-то потерять:

```
программа → ConPTY → vendor/vt100 → termview (ячейки → ratatui) → crossterm → Windows Terminal
```

1. **ConPTY** (системный, `CreatePseudoConsole` из `portable-pty`) держит свой буфер экрана и перерисовывает его для нас. Последовательности, которые conhost не понимает, он может не пропустить. Что именно доходит, зависит от версии Windows; проверять через `AFAR_PTY_RAW` (результат проверки — ниже, «Что пропускает ConPTY»). Windows Terminal использует собственную, более новую копию ConPTY (OpenConsole), поэтому «в голом Windows Terminal работает» ещё не значит «дойдёт до afar».
   - **Свой ConPTY.** `portable-pty` сначала ищет `conpty.dll` рядом с программой и только потом берёт системный из `kernel32` (`src/win/psuedocon.rs`, так делает WezTerm). Если положить рядом с `afar.exe` `conpty.dll` и `OpenConsole.exe` из Windows Terminal (MIT; пакет `Microsoft.Windows.Console.ConPTY`), ConPTY будет новым независимо от версии Windows. Минусы: два файла в поставке; в режиме разработки их нужно копировать вместе с exe в `%TEMP%\afar-dev`. Пропускает ли новый ConPTY волнистое подчёркивание и цвет подчёркивания — не проверено.
2. **`vendor/vt100`** хранит у клетки только символ, цвета (16, 256, truecolor), жирный, тусклый, курсив, подчёркивание и инверсию — пять битов байта `Attrs::mode` (`u8`, свободны три). Из OSC разбирает `0/1/2` (заголовок) и `52` (буфер обмена), звонок `BEL` — тоже; для них есть колбэки `vt100::Callbacks` (`set_window_title`, `copy_to_clipboard`, `audible_bell`), но в `Replies` (`term.rs`) они не реализованы — по умолчанию пустые. Остальное уходит в `Replies`: там отвечаем на DSR, DA, `OSC 10/11` и ведём `?2026`. Всё прочее молча пропадает. Это мигание, скрытый текст, зачёркивание, линия над текстом, виды и цвет подчёркивания, `OSC 8`, `OSC 9;4`, `OSC 133`, DECSCUSR, двойная ширина строк и Sixel.
3. **`termview`** переносит атрибуты клетки в `ratatui::Modifier`. Сейчас это `BOLD`, `DIM`, `ITALIC`, `UNDERLINED`, инверсия и цвета.
4. **ratatui / crossterm** умеют больше, чем приходит: `SLOW_BLINK`, `HIDDEN`, `CROSSED_OUT`, цвет подчёркивания (feature `underline-color` в ratatui 0.30 включена по умолчанию). Гиперссылок и картинок в ratatui нет: их пишут в обход буфера, отдельными последовательностями после кадра (как это делает `ratatui-image`).

Итог: Claude Code внутри afar выглядит беднее, чем в голом Windows Terminal. Ссылки на файлы не кликабельны, нет зачёркивания и волнистого подчёркивания, нет прогресса на панели задач и уведомлений. Почти всё это теряется не в ConPTY, а в `vt100` и `termview` (см. ниже).

### Что пропускает ConPTY (проверено 2026-10-07)

Системный ConPTY Windows 11 (сборка 26200): `python` печатает тестовые последовательности в командной строке afar, сырой вывод ConPTY — через `AFAR_PTY_RAW` (способ — в «Как проверять»).

| Проходит | Теряется |
|---|---|
| Зачёркивание `9`, мигание `5`, скрытый `8`, линия над текстом `53`, двойное подчёркивание `21` — ConPTY выводит их заново со своими сбросами (`29`, `25`, `28`, `55`, `24`) | Волнистое подчёркивание `4:3`: текст без подчёркивания вообще |
| Truecolor `38;2;…` | Цвет подчёркивания `58;2;…`: пропадает вся последовательность, вместе с `4` |
| `OSC 8` — ConPTY переписывает id ссылки (`id=<число>-<n>`) | |
| `OSC 9;4` (прогресс), `OSC 9` и `OSC 777` (уведомления), `OSC 133`, `OSC 9;9`, `OSC 52` | |
| Форма курсора `CSI 5 SP q`, звонок `BEL`, заголовок `OSC 2` (приходит как `OSC 0`) | |
| Двойная ширина строки `ESC#6` (ConPTY ставит `ESC#5` у остальных строк) | |

**Порядок.** OSC и последовательности без текста (прогресс, уведомления, форма курсора, звонок, заголовок) ConPTY отдаёт сразу, раньше текста, напечатанного до них. Порядок «текст → событие» по ним не восстановить: событие относится к программе, а не к месту на экране. `OSC 8` хранится в буфере ConPTY и приходит на своём месте.

## Что доработать для программ в PTY

**Сделано (2026-10-07):** пункты 1, 3 и 4 (`vendor/vt100`, `AFAR-PATCH`; `termview`; `app/links.rs`, `app/outer.rs`):
- `Attrs::mode` — `u16` (мигание, скрытый, зачёркнутый, линия над текстом), `Attrs::link` — id ссылки; клетка осталась 32 байта за счёт `CONTENT_BYTES` 22 → 19. Линия над текстом хранится, но не рисуется (в ratatui её нет). Виды подчёркивания (`4:x`, `21`) — как обычное подчёркивание, цвет подчёркивания (`58`) читается и отбрасывается (раньше его параметры принимались за другие атрибуты: `58;2;…` давал «тусклый»).
- `OSC 8`: URI ссылок — у экрана (`Screen::hyperlink(id)`, одинаковый URI — один id), `SGR 0` ссылку не заканчивает, стёртые клетки ссылкой не становятся. `Ctrl+щелчок` по ссылке в панели агента и на экране идущей команды: `file:` и абсолютный путь — папка в активной панели, файл в просмотрщике; `http`, `https`, `mailto` — программой Windows по умолчанию; остальные схемы не открываются. Пока зажат `Ctrl`, ссылки подчёркнуты. Агент запускается с `FORCE_HYPERLINK=1`.
- `OSC 9;4`, `OSC 9`, `OSC 777;notify`, звонок, заголовок собираются в `term::Signals` (`PtySession::take_signals`). Прогресс уходит на кнопку панели задач (файловые операции, иначе команда, иначе агент), уведомления — в строку сообщений с пометкой «Агент» / «Команда», звонок — во внешний терминал. Заголовок программ пока не используется.
- Сам afar: заголовок окна `{папка} - afar` и `OSC 9;9` (папка активной панели), прогресс файловых операций (жёлтый, пока над ним вопрос); при выходе прогресс снимается.

Правки в `vendor/vt100`, с меткой `AFAR-PATCH`, плюс перенос в `termview`. Порядок — от дешёвого к дорогому:

1. **Зачёркивание, мигание, скрытый текст, линия над текстом** (`9`, `5`, `8`, `53`): ещё четыре бита в `Attrs`, ветки в `Screen::sgr`, перенос в `Modifier`. В `mode` (`u8`) свободны только три бита — придётся расширить до `u16` (плюс байт на клетку экрана и истории прокрутки) или отказаться от линии над текстом, которой в ratatui всё равно нет.
2. **Виды и цвет подчёркивания** (`4:x`, `21`, `58`): поле в `Attrs`; ratatui выводит только цвет, вид надо дописывать своей последовательностью. Системный ConPTY пропускает только двойное подчёркивание, волнистое и цвет — только со своим ConPTY (см. звено 1).
3. **Гиперссылки `OSC 8`**: id ссылки в клетке плюс таблица ссылок у экрана. При выводе ссылку можно отдать внешнему терминалу (`OSC 8` вокруг участка) или открыть самим по щелчку: `Ctrl+щелчок` → файл в просмотрщике или папка в панели, URL → браузер. Второй вариант интереснее: ссылки Claude Code на файлы будут открываться прямо в afar.
4. **Прогресс `OSC 9;4`, уведомления `OSC 9`/`777`, звонок, заголовок**: прогресс и уведомления — в `Replies::unhandled_osc`, звонок и заголовок — готовые колбэки `audible_bell` и `set_window_title` (только реализовать). Пробрасывать во внешний терминал от имени панели: прогресс и «агент ждёт ответа» на кнопке панели задач, значок на рамке панели агента.
5. **Разметка команд `OSC 133`**: если её выводит оболочка внутри панели, по ней видны границы команд и коды выхода. Для журнала агента полезно, но наши команды и так идут отдельными процессами.
6. **Форма курсора DECSCUSR**: хранить у экрана и выставлять при фокусе на панели (у Claude Code и редакторов курсор-черта).
7. **Двойная ширина строк**: редкость, только если найдётся программа, которой это нужно.
8. **Sixel / картинки**: самое дорогое (хранение растра, размещение поверх ячеек, перерисовка при прокрутке) и упирается в то, пропустит ли их ConPTY. Пока не делать.

## Что может использовать сам afar

Это идеи, а не решения:

- **Прогресс файловых операций на панели задач** (`OSC 9;4`): Far показывает прогресс копирования на кнопке окна (через `ITaskbarList3`), а нам хватит одной последовательности. Красное состояние — вопрос об ошибке, жёлтое — пауза.
- **Уведомление**, когда агент закончил или ждёт разрешения, а окно не в фокусе (`?1004` даёт фокус). Плюс звонок.
- **Заголовок окна** как у Far: `{папка} - afar` (`OSC 2`).
- **Текущий каталог** (`OSC 7` или `OSC 9;9`): новая вкладка Windows Terminal откроется в папке активной панели.
- **Гиперссылки в своём выводе**, например пути в сообщениях об ошибках.
- **`OSC 52`**: копирование, когда afar запущен по SSH (`Ctrl+Ins` в панели, выделение в просмотрщике).
- **Анимация в стиле Claude Code** для состояния агента на рамке его панели («думает», «ждёт разрешения»). Truecolor и синхронный кадр уже есть.
- **Курсор-черта и курсор-блок** в редакторе (вставка и замена), как в Far.
- **Предпросмотр картинок** в быстром просмотре (`Ctrl+Q`) и просмотрщике: Sixel в Windows Terminal ≥ 1.22, полублоки как запасной вариант (`ratatui-image`).
- **Значки файлов** (Nerd Font) по желанию, с отдельной настройкой: шрифта может не быть.

## Как проверять

- Тестовые строки печатаются из командной строки afar. Команды идут через `cmd`, `printf` из Git Bash там нет — удобнее скрипт на Python в песочнице: `E = chr(27)`, `ST = E + chr(92)`, строки вида `print('strike:' + E + '[9mS' + E + '[0m')`, `print('link:' + E + ']8;;https://example.com' + ST + 'LNK' + E + ']8;;' + ST)`; метка перед каждой последовательностью помогает найти её в сыром выводе.
- `AFAR_PTY_RAW=<файл>`: что именно прислал ConPTY. Если последовательности в файле нет, её съел ConPTY, а не `vt100`. Под `pty_probe` в тот же файл пишется и вывод самого afar — его кадры (с рамками панелей) показывают, что осталось после `vt100` и `termview`.
- `pty_probe` с `PROBE_CELLS="строка,колонка;…"`: цвета и атрибуты клеток на экране afar.
- Сравнение: та же строка в голом Windows Terminal, в afar и в Far.
