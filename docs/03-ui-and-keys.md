Сверху вниз: строка меню → две файловые панели → **панель агента** (на всю ширину) → командная строка → строка функциональных клавиш.

### Состояния панели агента

| Состояние | Высота | Как попасть |
|---|---|---|
| Обычное | по умолчанию 35% высоты экрана (настройка), минимум 6 строк | по умолчанию |
| Развёрнутое | весь экран, кроме командной строки и keybar | команда `layout.agent_maximize` (по умолчанию `Ctrl+Shift+Space`) |
| Свёрнутое | 1 строка — заголовок со статусом | `layout.agent_collapse` |
| Скрытое | 0 | `layout.agent_hide` (сессия агента продолжает работать) |

Высота меняется клавишами `Ctrl+Up` / `Ctrl+Down` при фокусе на панелях — по аналогии с Far, где этими клавишами меняется высота панелей: панели становятся ниже, панель агента выше, и наоборот.

### Заголовок панели агента

`Агент ── <программа> ── <live-индикатор> ── <счётчик событий> ── <подсказка клавиши фокуса>`

- программа — что запущено в сессии (`claude`) и её состояние (`работает` / `завершён: код N` / `перезапуск: F5` при фокусе);
- live-индикатор: `● live` — события журнала автоматически передаются агенту с каждым запросом; `○` — только по запросу агента;
- счётчик — сколько событий накопилось с последнего запроса пользователя к агенту.

## Фокус

Возможные получатели ввода: левая панель, правая панель (с командной строкой — как в Far: печатные символы при фокусе на панели идут в командную строку), панель агента, режим терминала, просмотрщик, диалог.

| Клавиша | Действие |
|---|---|
| `Tab` | переключение между левой и правой панелью (как в Far). **В панели агента и в терминале `Tab` уходит программе** |
| `Ctrl+Space` | **переключатель фокуса**: панели → агент → панели. Из режима терминала с работающей командой — возврат к панелям (команда продолжает работать в фоне). Единственная клавиша, которая перехватывается у программ в агенте и терминале |
| мышь | щелчок по панели агента передаёт ей фокус; щелчок по файловой панели — возвращает |

Пока фокус в панели агента, **все** клавиши, кроме переключателя фокуса, передаются программе `claude` (в том числе `Esc`, `Tab`, `Ctrl+C`, F-клавиши). У панели с фокусом рамка подсвечивается, курсор файловых панелей рисуется неактивным.

> Открытый вопрос: `Ctrl+Space` выбрана потому, что не занята ни в Far, ни в Claude Code и надёжно различается в консоли Windows. Альтернативы — `F12` (в Far — список экранов) или `Ctrl+\``. Клавиша настраивается.

## Командная строка и терминал

- Ввод и `Enter` — как в Far. Встроенные команды (`cd`, `X:`, `cls`, `exit`) обрабатываются самим afar; остальные выполняются, и их вывод виден на **экране пользователя** — ленте из текста завершённых команд и живого экрана текущей.
- Каждая команда запускается отдельным процессом в своей PTY через настраиваемую оболочку (`cmd /c` по умолчанию на Windows, как в Far; можно выбрать `pwsh -NoLogo -Command` или `sh -c`). Так afar точно знает начало, конец и код возврата каждой команды, записывает их в журнал и сохраняет вывод для агента ([04-agent.md](04-agent.md#консольный-вывод)). Переменные окружения и текущий каталог хранит сам afar.
- `cls` очищает экран пользователя, но не сохранённый вывод команд.
- **Режим терминала** — полноэкранный слой с выводом команд (аналог «экрана пользователя» в Far):
  - `Ctrl+O` — показать/скрыть панели (как в Far), когда команда не выполняется;
  - при запуске команды afar переключается в режим терминала; после завершения — возвращается к панелям (как в Far); вывод остаётся доступен по `Ctrl+O`;
  - во время работы команды ввод идёт ей; `Ctrl+Space` — вернуться к панелям, не прерывая команду (в строке состояния появляется индикатор «выполняется: <команда>»);
  - `Shift+Enter` — запуск в отдельном окне (как в Far).
- Панель агента в режиме терминала остаётся на месте (настройка `agent.visible_in_terminal`).

## Диалоги

Стиль Far: серая рамка, кнопки `[ Копировать ]  [ Дерево ]  [ Фильтр ]  [ Отмена ]`, история в полях ввода. Диалоги — модальные *для ввода*, но не блокируют фоновые задачи, вывод агента и терминала: панель агента продолжает обновляться под диалогом.

Диалог копирования (F5): поле «Куда», параметры (перезапись: спрашивать / заменять / пропускать / заменять если новее / дописать; копировать права доступа; символические ссылки: как ссылки / содержимое), кнопки. Подтверждение команды агента — тот же диалог с заполненными полями и пометкой «Запрошено агентом».

## Просмотрщик (M2)

- Полноэкранный слой поверх панелей; панель агента остаётся внизу (настройка `agent.visible_in_viewer`).
- Текст (кодировки UTF-8 / UTF-16 / кодовые страницы), hex-режим, перенос строк, поиск, переход к строке.
- Большие файлы — чтение окнами (memory-map), без загрузки целиком.
- Открывается командой `view.open { path, line }` — агент может открыть файл на нужной строке.

## Цвета и тема

Тема `far-classic` повторяет палитру Far по умолчанию: панели — светло-голубой текст на синем, курсор — чёрный на бирюзовом, выделенные файлы — жёлтые, keybar — чёрный на бирюзовом с белыми номерами, диалоги — чёрный на сером. Раскраска файлов по маскам (как «Раскраска файлов» в Far) — M2.

Панель агента: рамка того же стиля, внутри — вывод программы как есть (её собственные цвета, 256/truecolor).

## Мышь

- щелчок — курсор, двойной щелчок — Enter, правая кнопка — выделение (как в Far);
- колесо — прокрутка панели / просмотрщика / истории терминала;
- щелчок по панели агента — фокус; в панели агента события мыши передаются программе, если она включила режим мыши;
- границы между окнами (между панелями, между панелями и агентом) перетаскиваются мышью — см. [08-windows.md](08-windows.md).
