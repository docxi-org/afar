# 08. Окна

afar будет показывать много разных окон: файловые панели, панель агента, экран пользователя, просмотрщики, редакторы, результаты поиска, список задач, диалоги, меню, со временем — несколько сессий агента. Расположением окон занимается оконный менеджер (`src/wm.rs`); содержимое окна рисует и обрабатывает его владелец.

## Понятия

| Понятие | Что это |
|---|---|
| **Окно** | Единица содержимого с идентификатором (`WinId`): `Panel(0/1)`, `Agent`, `UserScreen`, позже `Viewer(n)`, `Editor(n)`, `FindResults`, `Tasks`… |
| **Разбиение** (split) | Узел дерева раскладки: делит свою область на две части по горизонтали (`Row` — рядом) или по вертикали (`Column` — друг под другом). Граница между частями — **разделитель**, его можно двигать |
| **Размер разбиения** (`Extent`) | Как задан размер первой части: доля (`Ratio` — панели делят ширину пропорционально), фиксированный размер первой (`FirstFixed`) или второй части (`SecondFixed` — панель агента сохраняет высоту при изменении размера терминала). Плюс минимальные размеры обеих частей |
| **Экран** | Полноэкранное содержимое, между которыми переключаются (как `F12` в Far): «панели», «экран пользователя», позже — каждый открытый просмотрщик и редактор. У каждого экрана своё дерево разбиений |
| **Слот экрана** | Лист корневого дерева, в котором показывается текущий экран |
| **Закреплённое окно** (dock) | Окно в корневом дереве вне слота экрана — видно на любом экране. Сейчас это панель агента |
| **Оверлей** | Слой поверх раскладки: диалоги (F5, F7, F8…), меню (F9, F2), подсказки. Модальный для ввода — и для панели агента тоже, — но не останавливает фоновые задачи и вывод агента |
| **Постоянные строки** | Командная строка и строка функциональных клавиш внизу, строка меню вверху — вне дерева, как в Far |

## Текущая раскладка

```
корень: Column, SecondFixed(высота агента), минимумы (5, 5)
├─ слот экрана
│   ├─ экран «панели»: Row, Ratio(0.5), минимумы (20, 20)
│   │   ├─ Panel(0)
│   │   └─ Panel(1)
│   ├─ экран «экран пользователя»: UserScreen
│   └─ экраны просмотрщиков: Viewer(id), по одному на файл
└─ Agent   (закреплено)
командная строка, строка клавиш — вне дерева
```

- `Ctrl+O` переключает экраны «панели» ↔ «экран пользователя»; панель агента при этом остаётся на месте.
- `F12` — список экранов Far (панели и просмотрщики, горячие клавиши `0`–`9`, `A`–`Z`), `Ctrl+Tab` / `Ctrl+Shift+Tab` — по кругу. Экран пользователя в список не входит, он часть панелей. Закрытый просмотрщик возвращает к панелям.
- Панель агента может стоять **над** панелями: `[agent] position = "top"` в `config.toml` или «Параметры → Агент и разрешения» (`Wm::set_agent_on_top` меняет местами части корневого разбиения, высота агента сохраняется).
- В просмотрщике командная строка по умолчанию остаётся (`[viewer] command_line = true`), чтобы панель агента не сдвигалась при `F3`; `false` — как в Far, без неё.

## Управление

- **Мышь:** разделитель захватывается на двух клетках у границы — на соседних рамках двух окон (`║║` между панелями, нижняя рамка панелей / верхняя рамка агента) — и перетаскивается. Размеры ограничены минимумами окон.
- **Клавиатура (как в Far):** `Ctrl+←/→` — граница между панелями (при пустой командной строке), `Ctrl+↑/↓` — граница между панелями и агентом.

## Как устроено в коде

- `Wm::arrange(area) -> Arrangement`: прямоугольники окон, область слота экрана и список разделителей (с областью разбиения и координатой границы). Окно, которого нет на текущем экране, в результате отсутствует.
- `App` рисует окна по прямоугольникам из `Arrangement` и хранит последний результат для попадания мышью (`last_layout`).
- Перетаскивание: `Arrangement::grab` находит разделитель под курсором → `Splitter::first_for` переводит положение мыши в размер первой части → `Wm::set_first` применяет его с учётом минимумов и сохраняет вид `Extent`.
